# Postavka

Postavka — сайт доставки товарів з Китаю в Україну. На сайті описані морська й авіадоставка та перевезення збірних вантажів. Клієнт може розрахувати об’єм вантажу, підготувати дані для запиту й зв’язатися з менеджером.

- Сайт — [www.postavka.com.ua](https://www.postavka.com.ua/)
- Репозиторій — [Budpostach/Postavka](https://github.com/Budpostach/Postavka)
- Телефон — [+38 068 776 85 30](tel:+380687768530)

## Технології та файли

Сайт написаний на HTML, CSS і JavaScript. Для локального запуску не потрібні Node.js, встановлення залежностей або збірка.

| Файл | Призначення |
| --- | --- |
| `index.html` | Вхідна сторінка для адреси `/`. У поточній версії містить розмітку контактів. |
| `index (1).html` | Головна сторінка з описом послуг, калькулятором об’єму та запитаннями. |
| `style.css` | Спільні стилі й адаптивна верстка. |
| `app.js` | Розрахунок об’єму та підготовка тексту запиту на доставку. |
| `contact.js` | Підготовка чернетки SMS зі сторінки контактів. |
| `port.webp` | Зображення для головної сторінки. |

### Структура сторінок для публікації

У поточній гілці `main` обидва HTML-файли лежать у корені. Щоб головна відкривалась за `/`, а контакти — за `/kontakti/`, перемістіть файли в такому порядку.

1. Перемістіть поточний кореневий `index.html` у `kontakti/index.html`, а `contact.js` — у `kontakti/contact.js`.
2. Перейменуйте `index (1).html` на `index.html` у корені.
3. Залиште `style.css`, `app.js` і `port.webp` у корені. Опублікуйте переміщення одним комітом, щоб сторінки й посилання оновилися разом.

## Локальний запуск

Потрібні Git і Python 3. Відкрийте термінал і виконайте:

```bash
git clone https://github.com/Budpostach/Postavka.git
cd Postavka
python -m http.server 8000
```

Відкрийте [головну сторінку](http://localhost:8000/). Після впорядкування файлів перевірте також [сторінку контактів](http://localhost:8000/kontakti/).

## Форми й розрахунок

- **Розрахунок об’єму.** Для однакових коробок сайт множить довжину, ширину, висоту та кількість коробок. Розміри вводяться в сантиметрах, результат показується в м³. Наприклад, дві коробки 50 × 40 × 30 см мають загальний об’єм 0,12 м³.
- **Запит на доставку.** Форма готує текст для копіювання. Вартість і строки перевезення уточнює менеджер.
- **Контакти.** Форма готує чернетку SMS. Клієнт відкриває її в застосунку повідомлень і сам надсилає. Також можна зателефонувати за номером на сторінці.

## Публікація через Vercel

1. Внесіть зміни до репозиторію та об’єднайте їх із гілкою `main`.
2. У проєкті Postavka у Vercel відкрийте **Deployments** і перевірте статус нового розгортання.
3. Після публікації відкрийте [головну сторінку](https://www.postavka.com.ua/) і перейдіть у **«Контакти»** через меню. Перевірте калькулятор, кнопку дзвінка й відкриття чернетки SMS на телефоні.
